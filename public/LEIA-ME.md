# Imagens do site

Coloque os arquivos de imagem **nesta pasta**. Tudo que estiver aqui fica
acessível na raiz do site: `public/fantasma.png` vira `/fantasma.png`.

## Como subir pelo site do GitHub

1. Abra esta pasta no GitHub
2. **Add file → Upload files**
3. Arraste o arquivo e confirme com **Commit changes**
